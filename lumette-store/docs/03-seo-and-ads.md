## SEO writing rules (apply to every product, collection and page)
- **Product SEO title (<= 60 chars):** `Primary keyword + differentiator` -> "Satin Sleep Bonnet, Adjustable | Lumette". Edit under "Search engine listing" on each product.
- **Meta description (130-155 chars):** one sentence of what it is, one of the key benefit, delivery or returns hook. e.g. "A soft satin-feel sleep bonnet with an adjustable elastic band. 30-day returns. Shipping to the US and Canada." No claims you can't back up.
- **Collection titles:** `Heatless Hair Tools & Accessories | Lumette`. Write 80-150 words of real introduction text at the top of each collection (what's in it, how to choose) - this is the main text Google reads for category pages.
- **URL handles:** short, lowercase, descriptive (`satin-sleep-bonnet`). Don't change handles after launch without a redirect (Shopify offers to create one).
- **Alt text:** `[Product] [variant], [what's shown]`, <= 125 chars.
- **Internal links:** link collections to each other in the intro text, products to their collection via breadcrumbs (done by the theme) and the "You may also like" block.
- **Blog (optional, supports organic):** guides such as "How to use heatless curlers overnight" bring non-ad traffic. Templates `blog` and `article` are included.

## Google Merchant Center feed
**Primary route (recommended): the Google & YouTube Shopify app.** It creates and syncs the feed live (price, stock, variants), verifies and claims your domain, and can install GA4/Ads tags and purchase conversion tracking. Connect it and your Merchant Center account in one flow.

**Feed audit and fallback: `tools/merchant_feed.py`.** Export products (Products > Export > All products > CSV for Excel) and run:
```
python3 tools/merchant_feed.py products_export.csv feed.tsv --domain yourdomain.com --brand Lumette --currency USD
```
It outputs a tab-separated Merchant Center file with: `id, title, description, link, image_link, additional_image_link, availability, price, condition, brand, gtin, mpn, identifier_exists, google_product_category, product_type, item_group_id, color, size, shipping_weight, adult`, and blocks (exit code 1) on: missing title/image, title > 150 chars, ALL-CAPS title, promotional text in titles ("free shipping", "% off"), price <= 0, duplicate IDs, non-https images. It warns on: weak descriptions, health/medical claim words, invalid GTIN lengths, missing product type. Pass `--taxonomy` with Google's taxonomy file to validate `google_product_category`. Limitations: variant links point to the product URL (no variant ID in the export), and it doesn't set shipping, tax or return policy.

### Merchant Center compliance checklist (what causes dropshipping stores to be suspended)
- [ ] Website shows real **business name, address and contact email** (footer + Contact page + policies). Fill the `{{...}}` fields.
- [ ] **Shipping policy and returns policy** are published and match what's in Merchant Center settings (shipping rates and transit times, return window of 30 days).
- [ ] **Delivery times in Merchant Center match reality.** Enter the realistic range for CJ's lines (e.g. handling 1-3 days, transit 7-15 days for China shipments). Understated times are a leading cause of "misrepresentation" suspensions.
- [ ] Price on the landing page equals the feed price (including currency per country). Automatic item updates on.
- [ ] Checkout works over HTTPS, accepts the payment methods you list.
- [ ] No watermarks, logos or promo text on images; main image on a plain background.
- [ ] Brand = your store name for own-label items. For unbranded goods set `identifier_exists = no`. Don't invent GTINs.
- [ ] No prohibited claims (medical, "anti-aging", "cure"); no counterfeit/look-alike goods.
- [ ] Set up **tax** (US: Merchant Center settings can use "Shopify's calculation"; Canada: prices are tax-exclusive by default).
- [ ] Verify and claim the domain.
- [ ] Diagnostics tab is clean 24-72 h after first sync before launching Shopping ads.

## GA4 and Google Ads: two ways. Pick ONE.
**Option A (recommended): Google & YouTube app handles everything.** Connect GA4 and Google Ads inside the app, enable "Enhanced conversion tracking" and purchase tracking. Leave **Theme settings > Tracking** *off*.

**Option B: theme hooks + Custom Pixel.** For people who want manual control.
1. Theme settings > Tracking (Google): tick *Enable theme tracking hooks*, paste GA4 ID (`G-...`) and Google Ads ID (`AW-...`). The theme then fires: GA4 config, `view_item` (product), `view_item_list` (collection, first 24), `add_to_cart` (with value) and optional Google Ads add-to-cart conversion label, plus `generate_lead` on popup sign-ups. Consent defaults to *denied* and updates from Shopify's Customer Privacy API (cookie banner).
2. For checkout events (theme code can't run on checkout): Settings > Customer events > Add custom pixel > paste `tracking/custom-pixel.js`, fill in the three constants, Save and **Connect**. It sends `begin_checkout`, `purchase` (with transaction ID, tax, shipping, items) and the Google Ads purchase conversion.
3. Validate in GA4 DebugView and Google Ads Tag Assistant before spending money; make a test order.
- **Do not run A and B together.** Revenue would be double-counted.
- Custom pixels run in a sandbox; sessions can be split between storefront and checkout. Option A handles this better.

## Campaign plan once organic shows traction
1. **Gate to start paying for ads:** pick products with real organic signal. Rule of thumb (not a law): >= 5 organic orders **and** add-to-cart rate >= 5% of product views **and** margin >= 50% before ads. Below that, keep creating content.
2. **Shopping/Performance Max:** Google has been moving new Shopping setups into Performance Max with a product feed; check which campaign types your account offers. Start with one campaign, the 3-5 best-converting products only, daily budget small enough you can lose it (e.g. $10-20), run 2+ weeks before judging.
3. **Search:** exact/phrase keywords on product nouns ("heatless curlers", "satin sleep bonnet"). Add negatives: free, diy, wholesale, bulk, reviews, "how to make".
4. **Remarketing/Customer lists:** after 1,000 audience members for display; email list uploads for customer match when you have >= a few hundred customers.
5. Landing page = the product page (not the home page). Sticky add-to-cart and delivery estimate are already there.
6. **Break-even ROAS** = 1 / margin-before-ads (e.g. 55% margin -> 1.8 ROAS). Don't scale below it.
