# Page and policy copy (English)

Paste each file into the matching Shopify **Page** (Online Store > Pages) using the HTML editor (`<>` icon).
The same legal text also goes into **Settings > Policies** (Shopify needs those for checkout links).

## Merge fields to replace before publishing
| Field | Meaning |
|---|---|
| `{{BRAND}}` | Brand name (default `Lumette`) |
| `{{LEGAL_NAME}}` | Your registered business name |
| `{{BUSINESS_ADDRESS}}` | Legal mailing address (required by Shopify and by CAN-SPAM/CASL) |
| `{{SUPPORT_EMAIL}}` | Customer support inbox |
| `{{RETURN_ADDRESS}}` | Where returns are sent (confirm with CJ; may be a US/CA returns address or none) |
| `{{EFFECTIVE_DATE}}` | Date the policy takes effect |
| `{{JURISDICTION}}` | Province/state whose law governs (e.g. Ontario, Canada) |

Template handles: About -> `page.about`, Contact -> `page.contact`, Track your order -> `page.track-order`,
FAQ -> `page.faq`, all policy pages -> default `page`.

These policies are drafts written for a dropshipping store selling beauty tools in the US and Canada.
They are **not legal advice**. Have a lawyer review them (and the French versions) before launch.
