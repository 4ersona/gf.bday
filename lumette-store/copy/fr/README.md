# Contenu des pages et politiques (français canadien)

À coller dans les mêmes pages Shopify que les versions anglaises, via **Translate & Adapt** (application gratuite de Shopify)
une fois la langue française ajoutée dans **Paramètres > Langues**. Les textes de l'interface (boutons, panier, filtres) sont
déjà traduits dans `theme/locales/fr.json`. Le contenu modifiable dans l'éditeur de thème est traduit via Translate & Adapt
avec le tableau de `theme-content-fr.md`.

Mêmes champs à remplacer que dans la version anglaise (`{{BRAND}}`, `{{LEGAL_NAME}}`, etc.).

**Avertissement :** ces textes ont été rédigés avec l'aide d'une IA, ne sont pas un avis juridique et doivent être relus par une
personne de langue maternelle française (idéalement québécoise) et par un juriste avant le lancement. Si vous vendez au Québec, la Charte de la langue
française (Loi 96) exige que le site, les conditions et le service à la clientèle soient offerts en français.
